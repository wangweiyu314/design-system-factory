---

📌 **三个真实卡点**

**1️⃣ 规范读不进，也读不全**  
几十页规范塞不进上下文，Agent 只看得到片段，  
剩下的颜色间距全靠它自己猜。

**2️⃣ 写错了没人发现**  
硬编码色值、数值漂移，混在几百行 diff 里。  
CSS 不报错、页面能跑、人眼也抓不住。

**3️⃣ 没有门禁，全靠自觉**  
prompt 里写了「必须遵守规范」，Agent 转头就忘。  
没有任何机制真的拦得住它。

---

✅ **我的解法：把规范做成机器能执行的约束**

Figma 变量 + 线上真实样式 → 自动生成一套设计系统技能包：

· 规范文档（Token 单一真值源）  
· 11 套 HTML 模板  
· Token 校验器：硬编码 / 取值漂移 / 未收编，双向比对  
· 提交门禁：不合规直接卡在 git commit  
· 页面生成器：一句话出列表页 / 表单页 / 详情页

**实测数据**

· 110 个 Token 双向校验全通过，退出码 0  
· 1121 处前缀替换，0 残留  
· 5 分钟完成建包

---

⚠️ **一个提醒：第 3 步「人工裁决」千万别省**

机器算得出频次，算不出哪个是主色。  
这步跳过，后面全白做。
